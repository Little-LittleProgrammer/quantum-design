# 总览

`@quantum-design/*`为Web应用提供了丰富的基础UI组件, 方法, 配置, 可以做到Web应用项目90%代码重复度的降低

::: danger 注意事项

1. 代码演示, 只展示重要片段, 不代表全部代码
2. 所有包版本已统一升级至3.0.0，支持最新的Vue3.5和Vite7技术栈
3. 新增AI Hub包，支持多种AI服务集成

:::

1. [强大的hooks](/packages/hooks/) - v3.0.0
    - 新增useDesignTokens、useOriginTableSort、usePriorityValue等hooks
    - 优化现有hooks的性能和类型安全

2. [强大的http通讯](/packages/http/) - v3.0.0
    - 全面支持Axios 1.11.0最新特性
    - 增强错误处理和重试机制

3. [强大的共享文件](/packages/shared/) - v3.0.0
    - 新增颜色工具和主题管理
    - 扩展枚举类型定义

4. [强大的ts类型库](/packages/types/) - v3.0.0
    - 完善Vue3和全局类型定义
    - 新增PWA和路由类型支持

5. [强大的utils 工具库](/packages/utils/) - v3.0.0
    - 性能优化和体积缩减
    - 新增更多实用工具函数

6. [丰富的 vue3 通用组件](/packages/vue3-pc-ui/) - v3.0.0
    - 支持Vue3.5最新特性
    - 优化组件性能和可访问性

7. [丰富的 vue3 antd 组件](/packages/vue3-antd-pc-ui/) - v3.0.0
    - 支持Ant Design Vue 4.2.6
    - 新增更多业务组件

8. [丰富的 styles 样式库](/packages/styles/) - v3.0.0
    - 支持Dark Mode主题切换
    - 优化Tailwind CSS集成

9. [强大的 AI 集成库](/packages/ai-hub/) - v3.0.0
    - 支持阿里云、OpenAI等多种AI服务
    - 提供统一的AI接口封装

10. [vue3 element组件](/packages/vue3-ele-pc-ui/) - v3.0.0
    - 全新升级，支持Element Plus最新版本
